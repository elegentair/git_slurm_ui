This is an application that, when running on a computer with slurm configured, allows students to type a Git repo link that contains a job for the computer to run via slurm. It also uses rclone to open a web browser for students to sign into Google accounts to allow access to their Google drive. Job results (not only output files, but any file generated by the job) are uploaded back to Google Drive.
